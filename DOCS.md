# Utilisation

Ouvrir « Dépendances » dans la barre latérale. Cliquer **Analyser** pour lire les fichiers
Home Assistant et créer l'index. Filtrer par domaine, portée de catégorie ou recherche.
Cliquer sur un objet pour consulter les propriétés, sa configuration et ses relations.
Cliquer sur un identifiant dans « Dépend de » ou « Utilisé par » pour naviguer.
Le symbole ⚠ indique une référence absente de l'inventaire.

L'analyse ne modifie pas les entités, les automatisations ou les helpers.
